# 자산운용 학습서 — 비전공자를 위한 두 트랙 학습서

대학원 수업 "자산운용을 위한 인공지능"의 내용을 **금융 비전공자**도 처음부터 따라갈 수 있도록 재구성한 학습서입니다.

## 핵심 원칙

모든 개념은 **"왜?"** 로 시작합니다.

- 왜 이 개념을 알아야 하는가?
- 왜 이 수식이 나오는가?
- 왜 이 단계에서 이 변환을 하는가?

"왜?"가 끊기지 않고 이어지는 것이 이 학습서의 품질 기준입니다.

## 학습서 구조 — 두 트랙

```
[자산운용 트랙]                     [AI 수학·ML 트랙]
01~14 (메인)                        A1, B1, B2 (수학·ML 도구)
무엇을 어떻게 운용하는가             그 운용을 가능케 하는 수학·ML
```

두 트랙은 후속 강의에서 합류 예정 (예: ML을 자산운용에 적용).

## 특징

- **전문 용어**: 처음 등장 시 한글 풀이 + 직관적 비유 포함
- **수식 유도**: "자명하다" 없이 모든 단계를 설명
- **개념 의존 순서**: 강의 시간순이 아닌, 이해에 필요한 순서로 재구성
- **셀프체크**: 매 단원 끝에 이해 확인 질문 포함
- **두 트랙 구조**: 자산운용 본 트랙 + AI 수학·ML 보조 트랙
- **출처 추적**: 강의 녹취 (`[강의 3/27, 02:12]`), 슬라이드 (`[l3.pdf p.12]`), 논문 (`[Moskowitz 2012, p.230]`) 모두 명시
- **시각화**: 모든 단원에 이해를 돕는 그림 — Matplotlib PNG (`figures/`) + Mermaid 다이어그램 (md 직접 임베드)

## 시각화 환경 (옵션)

그림을 다시 생성하려면:

```bash
pip3 install --user --break-system-packages matplotlib numpy
python3.13 scripts/ch13_momentum_smile.py   # 단일 그림
for s in scripts/ch*.py; do python3.13 "$s"; done   # 전체 재생성
```

Mermaid 자동 렌더링은 VSCode `Markdown Preview Mermaid Support` 확장으로 활성화.
