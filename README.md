# 자산운용 학습서 — 비전공자를 위한 12단원 시리즈

대학원 수업 "자산운용을 위한 인공지능"의 내용을 **금융 비전공자**도 처음부터 따라갈 수 있도록 재구성한 학습서입니다.

## 핵심 원칙

모든 개념은 **"왜?"**로 시작합니다.

- 왜 이 개념을 알아야 하는가?
- 왜 이 수식이 나오는가?
- 왜 이 단계에서 이 변환을 하는가?

"왜?"가 끊기지 않고 이어지는 것이 이 학습서의 품질 기준입니다.

- **전문 용어**: 처음 등장 시 한글 풀이 + 직관적 비유 포함

- **개념 의존 순서**: 강의 시간순이 아닌, 이해에 필요한 순서로 재구성
- **셀프체크**: 매 단원 끝에 이해 확인 질문 포함
